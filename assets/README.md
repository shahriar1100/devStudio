# Image assets

The website already works with lightweight SVG placeholders. Replace these files with your final images, or update the paths in `assets/js/projects.js`.

## Work carousel

Recommended size: **1600 × 1000 px** (8:5 ratio), JPG/PNG/WebP/SVG.

- `images/work/work-01.svg` — primary UI design
- `images/work/work-02.svg` — website mockup
- `images/work/work-03.svg` — mobile/product UI
- `images/work/work-04.svg` — branding project
- `images/work/work-05.svg` — dashboard/e-commerce project

To use PNG or WebP files, place them in `images/work/` and change only the relevant `image` value in `assets/js/projects.js`.

## Contact illustration

- `images/contact/contact-illustration.svg` — the character above the contact card

Recommended transparent image size: **700 × 800 px**.
